# 边线 · 体育资讯

一个为个人阅读设计的轻量 PWA，聚合 NBA、欧洲足球和英雄联盟资讯。无需账号，收藏保存在当前设备，支持添加到手机桌面和离线查看最近内容。

## 更新资讯

数据源配置位于 `public/data/sources.json`。运行下面的命令会读取启用的 RSS，去重后写入 `public/data/feed.json`：

```powershell
python scripts/collect_feeds.py
```

仓库包含免费的定时更新工作流，每小时运行两次。某个来源失效时不会影响其他频道，直接替换对应 RSS 地址即可。

## 本地运行

安装依赖后执行：

```powershell
npm run dev
```

浏览器访问显示的本地地址。手机与电脑在同一网络时，也可以通过电脑的局域网地址访问。

## 数据原则

- 只保存标题、短摘要、发布时间、来源和原文链接。
- 不复制新闻全文和来源图片。
- 赛程数据未接入可靠 API 前会明确标注“演示赛程”。
- 免费第三方来源可能调整地址或访问策略，需要不定期维护。
